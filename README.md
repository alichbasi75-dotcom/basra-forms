# بوابة استمارات مراكز التسجيل - مكتب انتخابات البصرة
### Basra Registration Centers Forms Portal

نظام إلكتروني متكامل وتفاعلي يتيح لـ (76) مركز تسجيل في محافظة البصرة استعراض وتنزيل وملء وطباعة الاستمارات الرسمية المعتمدة لعام 2026 بدقة عالية وبسهولة تامة.

---

## 🌟 مميزات النظام على GitHub Pages
1. **سرعة فائقة واستقرار دائم (24/7):** يعمل عبر شبكة التوزيع العالمية (CDN) الخاصة بـ GitHub بدون توقف وبدون الحاجة لتشغيل أي سيرفر محلي.
2. **استيعاب متزامن غير محدود:** يستوعب دخول جميع مراكز التسجيل (76 مركزاً) في نفس اللحظة وتنزيل الاستمارات بدون بطء.
3. **معاينة تفاعلية لكافة الاستمارات:** استعراض صفحات الاستمارات والكتب الرسمية بدقة A4 عالية.
4. **محاذاة وكتابة فورية:** إمكانية إضافة مربعات نصوص بالسحب والإفلات وتعبئة البيانات قبل الطباعة.
5. **طباعة مباشرة بحجم A4:** طباعة الاستمارة مع النصوص المكتوبة بجودة مطبعية.
6. **تنزيل الملفات الأصلية:** إمكانية تنزيل الملف الأصلي (Word / Excel / PDF) مباشرة بنقرة واحدة.

---

## 📂 هيكلية المشروع
- `index.html`: البوابة الرئيسية التفاعلية لمراكز التسجيل.
- `data/`: قواعد البيانات المصنفة (الاستمارات، التصنيفات، بيانات مراكز التسجيل الـ 76).
- `sheets/`: الصور المعالجة عالية الدقة لصفحات الاستمارات بدقة A4.
- `uploads/`: الملفات الأصلية المعتمدة (Word / Excel / PDF).
- `.nojekyll`: لضمان عمل GitHub Pages بشكل فوري ومباشر دون معالجة إضافية.
